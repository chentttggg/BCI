# 通道映射与参考配置

## 默认绑定（config/channel_config.json）

| 硬件 Channel | 电极标签 | 说明 |
| --- | --- | --- |
| 0 | Fz | 额中线 |
| 1 | Cz | 中央中线 |
| 2 | P3 | 左顶 |
| 3 | Pz | 顶中线（P300 核心） |
| 4 | P4 | 右顶 |
| 5 | PO7 | 左顶枕 |
| 6 | PO8 | 右顶枕 |
| 7 | Oz | 枕中线 |

- REF：A1（左耳垂/左乳突），若帽子上无此电极则按实际贴片填写。
- GND：Fpz（前额接地），若实际使用 AFz 或其它位置，必须同步修改配置。

## 重要规则

- 物理连线决定信号来源；JSON 标签只负责赋予通道生物学意义。
- REF、GND 标签不得与 8 个 EEG 通道重复。
- 因为 Cz 是记录通道，**不能**使用说明书默认 REF=Cz 方案。
- 每次实验前打印/核对映射，并把最终 ref/gnd 写入 session.json。
