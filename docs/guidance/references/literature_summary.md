# 文献要点与本次改进对照

## 原始文献（Moucek et al., 2017）

| 项目 | 原文 |
| --- | --- |
| 范式 | 猜数字 P300 oddball；1–9 随机闪现；target=受试者默想数字 |
| 通道 | Fz, Cz, Pz（标准 V-Amp 湿电极帽，另有参考/接地/EOG） |
| ISI | 1500 ms |
| 数据处理 | 原始数据公开；在线仅作可视化；趋势漂移用 0.5 Hz 高通处理 |
| epoch | -500 ~ +1000 ms，基线 -500 ~ 0 ms |
| 决策 | 实验者观察各数字平均 ERP 波形猜测 |

## 本次实验改进

| 改进点 | 理由 |
| --- | --- |
| 8 通道 Fz, Cz, P3, Pz, P4, PO7, PO8, Oz | P300 地形覆盖中线-顶枕，比 3 通道提供更多空间模式 |
| ShallowConvNet 单试次分类 | 从人工看平均波形升级为可训练的神经算法 |
| 平衡随机 block（每数字等次数） | 保证每类试次数均衡，利于训练与在线聚合 |
| 500 Hz 原始采样 + 后端 250 Hz 模型输入 | 保留原始精度，模型使用标准带宽 |
| LSL + EDF annotation + JSONL 三重打标 | 提高事件时间精度，满足宪法可追溯要求 |
| 个人化多次 session 训练 + 集成 | 单人 BCI 校准；多 seed/多折集成提高稳定性 |
| 保守伪迹标记 + 训练剔除/推理排除 | 不静默删除数据；提高训练与聚合质量 |
