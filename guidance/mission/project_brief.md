# Mission — 猜数字 P300 个人化 BCI 项目

## 1. 项目目标

- **复现**：复现 Moucek et al. 2017 “Guess the number” P300 oddball 实验的数据采集范式。
- **改进**：在原始文献的三通道（Fz, Cz, Pz）基础上扩展为本机 8 通道干电极
  （Fz, Cz, P3, Pz, P4, PO7, PO8, Oz），并使用 ShallowConvNet 作为信号处理/分类核心。
- **优化**：算力优先级低；在遵守宪法“保守预处理、可复现、可追溯”前提下，优先提高识别准确率。
- **交付物**：
  1. 实验前端程序（视觉刺激呈现、BrainSync 数据采集、LSL 打标、原始数据保存）。
  2. 后端处理程序（导入、QC、预处理、伪迹处理、ShallowConvNet 训练/推理/评估）。
  3. 指导文件夹与运行文档。

## 2. 实验对象与场景

- **对象**：单人、多次测试（多次 session）。
- **电极**：8 通道干电极帽，位置 Fz、Cz、P3、Pz、P4、PO7、PO8、Oz。
- **设备**：BrainSync BS8A（EEG 8 通道 + REF + GND），USB 有线连接优先。
- **任务**：受试者默想 1–9 中一个数字并默数目标数字出现次数；屏幕随机呈现 1–9；
  系统在若干试次后给出猜测。

## 3. 不可妥协原则（继承 Constitution 1.2）

1. 原始 EDF/日志只读，不得覆盖或删除；处理从派生副本开始。
2. 每一步记录软件版本、参数、随机种子、输入输出 SHA-256。
3. 所有中间/最终文件携带 provenance JSON sidecar。
4. 默认最小充分处理；不确定的数据标记并保留，不静默删除。
5. 质量门禁不可跳过；失败数据必须标记并报告。
6. 关键节点保存快照，支持回滚。
7. 同一文件同一时刻只允许一个 agent 写入；写入原子化。
8. 不为了拟合结果过度调参；重大技术调整写入 `guidance/tech_stack/decisions_log.md`。

## 4. 重大错误红线（本项目特别补充）

- 禁止在未记录 `ref_label`、`gnd_label`、通道索引映射的情况下采集或重参考。
- 禁止把软件在线滤波后的信号当作原始信号保存为唯一记录。
- 禁止在训练集中使用测试 session 的任何统计量（包括归一化参数、伪迹阈值、模型选择）。
- 禁止未经文档化的试次/通道插值。
- 禁止在没有时间对齐验证的情况下直接使用前端软件标记作为刺激 onset。

## 5. 成功标准

| 指标 | 门槛 | 目标 |
| --- | --- | --- |
| 9 选 1 block 级识别准确率 | > 1/9 随机水平 | ≥ 60% |
| 目标试次 AUC | ≥ 0.70 | ≥ 0.85 |
| 数据完整性 | 100% 文件哈希入库 | 100% |
| QC 可复现 | 每个 session 生成 QC 报告 | 每次必做 |

> 门槛是继续进入下一阶段的最低条件；目标是“尽量拉高识别准确率”的调优方向。
